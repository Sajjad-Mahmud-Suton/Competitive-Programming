# Competitive Programming

Welcome to my Competitive Programming repository! Here, I share my C++ programming materials, codes from competitive programming contests, and solutions to various problems that I have solved during my journey.

---

## 📚 Repository Contents

- **C++ Materials**: Includes all my class materials, assignments, and resources related to C++ programming.
- **Competitive Programming Contests**: Contains the solutions I've submitted for various competitive programming contests.
- **Problem Solving**: Solutions to algorithmic problems from various online judges like Codeforces, LeetCode, HackerRank, etc.

---

## 🚀 Purpose

This repository is designed to keep track of my progress in competitive programming and to have a collection of important concepts, algorithms, and strategies I have learned throughout my studies. It also helps me keep the solutions and materials organized and available for future reference.

---

## ⚙️ Technologies Used

- **C++**: The primary programming language used for solving problems.
- **Algorithms & Data Structures**: Implementations of various algorithms, from sorting and searching to graph algorithms and dynamic programming.

## 🌱 Learning Goals

- **Improve problem-solving skills**: By consistently solving problems in competitive programming contests.
